# GlobusIPTV — Личный кабинет

Демонстрационный личный кабинет для IPTV-сервиса: вход, баланс и подписка, данные для подключения (M3U/хост/логин/пароль), история операций и настройки. Полностью статическая страница, всё состояние хранится в `localStorage` браузера — бэкенда нет.

## Запуск

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000/dashboard/`. Либо просто открыть `dashboard/index.html` напрямую в браузере.

## Возможности

- Вход по имени/email (демо, без реальной проверки пароля)
- Обзор: баланс, текущий тариф, подключённые устройства, последние операции
- Подключение: хост, логин, пароль и ссылка M3U с копированием в буфер и генерацией новых данных
- Профиль: редактирование имени, email, телефона
- Подписка: три тарифа (Старт / Оптимальный / Максимум) с переключением и списанием с баланса
- История операций в виде таблицы
- Настройки: тёмная тема, уведомления, удаление демо-аккаунта

## Структура проекта

```
index.html      разметка страницы
css/style.css   оформление и цветовые темы (светлая/тёмная)
js/app.js       логика: состояние, рендер разделов, localStorage
```
