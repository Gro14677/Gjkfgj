# Orbit — Личный кабинет

Демонстрационный личный кабинет в стиле «мой аккаунт»: вход, обзор баланса и подписки, профиль, история операций и настройки. Полностью статическая страница, всё состояние хранится в `localStorage` браузера — бэкенда нет.

## Запуск

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000/dashboard/`.

## Возможности

- Вход по имени/email (демо, без реальной проверки пароля)
- Обзор: баланс, текущий тариф, использование трафика, последние операции
- Профиль: редактирование имени, email, телефона
- Подписка: три тарифа (Basic / Pro / Premium) с переключением
- История операций в виде таблицы
- Настройки: тёмная тема, уведомления, удаление демо-аккаунта

## Структура проекта

```
index.html      разметка страницы
css/style.css   оформление и цветовые темы (светлая/тёмная)
js/app.js       логика: состояние, рендер разделов, localStorage
```
