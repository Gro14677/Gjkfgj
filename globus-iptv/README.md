# Globus IPTV — личный кабинет

Панель управления IPTV-сервисом: подписки, каналы, плейлисты, устройства, финансы,
партнёрская программа и поддержка. Сделано по мотивам кабинетов вида
`my.vivamax.pro/dashboard`, но с расширенным набором разделов и живой демо-логикой.

Сервер и сборка не нужны — это обычная статическая страница.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/globus-iptv/` (или просто `index.html` в браузере).

**Демо-доступ:** логин `demo`, пароль `demo` (кнопка «Подставить демо-доступ» заполняет поля).

Сквозные вещи: тёмная и светлая темы, русский и английский языки, палитра команд
(`Ctrl`/`Cmd` + `K`) с поиском по разделам, подпискам и каналам, всплывающие уведомления,
колокольчик с непрочитанными, адаптив до 390 px с выдвижным меню.

## Как это работает

Действия реально меняют состояние: создание подписки списывает кредиты и добавляет
операцию в историю, продление сдвигает дату окончания, пополнение увеличивает баланс.
Всё состояние лежит в `localStorage` браузера (ключ `globus-iptv:v1`) — ни на какой
сервер данные не уходят. Сброс: «Настройки → Опасная зона» или меню профиля.

Раз в 9 секунд фоновый таймер меняет часть линий между «в эфире» и «не в сети»,
чтобы обзор и устройства выглядели живыми.

Плеер, ссылки на потоки и платежи — демонстрационные: настоящий стрим и оплата
не подключены.

## Структура

```
index.html            точка входа
css/style.css         оформление, темы, адаптив
js/data.js            демо-данные и хранилище (localStorage)
js/i18n.js            словари RU/EN и формы множественного числа
js/ui.js              иконки, форматирование, графики на SVG, модалки, тосты, таблицы
js/views-core.js      обзор, подписки, каналы, плейлисты, устройства, общие модалки
js/views-more.js      статистика, финансы, тарифы, партнёрка, поддержка, настройки
js/app.js             вход, маршрутизация по #-адресам, шапка, меню, палитра команд
```

Внешних зависимостей нет: графики нарисованы вручную на SVG, иконки — инлайновые,
из сети подгружаются только шрифты (без них страница работает на системных).
