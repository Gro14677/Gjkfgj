# Terrarium Snake

Классическая змейка, оформленная как экспонат стеклянного террариума: конденсат на стекле, почва снизу и ягоды вместо яблок.

## Запуск

Игра — обычная статическая веб-страница, сервер не нужен. Достаточно открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Управление

- Стрелки или `WASD` — движение
- `Пробел` — пауза
- Свайп по игровому полю или экранная крестовина — управление с телефона

## Структура проекта

```
index.html      разметка страницы
css/style.css   оформление и цветовые темы (светлая/тёмная)
js/game.js      логика игры на canvas
```

Рекорд по длине змея сохраняется в `localStorage` браузера.
