# Wildwood Arcade

Небольшой браузерный игровой сборник на чистом HTML/CSS/JS, без сборки и зависимостей.

## Запуск

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000` — попадёшь в меню, откуда доступны обе игры. Можно и просто открыть `index.html` в браузере напрямую.

## Игры

### Canopy Runner (`platformer/`)
2D-платформер с персонажем: лис бежит по лесной роще, прыгает по веткам и брёвнам, обходит или запрыгивает на жуков-врагов, собирает жёлуди и добегает до фонаря в конце уровня.

- `A`/`D` или стрелки — бег
- `Пробел`/`W`/`↑` — прыжок (держи для прыжка выше, отпусти раньше — прыжок короче)
- `R` — начать заново
- Экранные кнопки — управление с телефона

Лучшее время прохождения сохраняется в `localStorage`.

### Terrarium Snake (`snake/`)
Классическая змейка, оформленная как экспонат стеклянного террариума: конденсат на стекле, почва снизу, ягоды вместо яблок.

- Стрелки/`WASD` — движение
- `Пробел` — пауза
- Свайп по полю или экранная крестовина — управление с телефона

Рекорд по длине змея сохраняется в `localStorage`.
